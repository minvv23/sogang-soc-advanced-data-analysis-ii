## 6. 결론

### 가설 검정 결과: 기각 (방향 반대)

상호작용항 B(여성 x 나이) = **-0.052** (p = .044)로 통계적으로 유의하나, 방향이 가설과 **반대**다.

- 가설: 어릴수록 성별 차이 확대 - 상호작용항 양(+) 기대
- 결과: 나이 많을수록 성별 차이 확대 - 상호작용항 **음(-)**

### 효과의 원천: 여성이 견인

| 연령대 | 남성 | 여성 |
|--------|------|------|
| 16-19세 | 3.836 | 2.626 |
| 20-22세 | 3.851 | 2.434 |
| **변화** | **+0.015 (불변)** | **-0.192 (진보화)** |

- 남성: 나이와 무관하게 3.8대에 고정 (나이 기울기 = +0.005, 사실상 0)
- 여성: 나이 들수록 진보적 이동 (나이 기울기 = 0.005 - 0.052 = **-0.047**)

**어린 청소년일수록 성별 차이가 작은 이유는 남성이 덜 보수적이어서가 아니라, 여성이 아직 덜 진보적이기 때문이다.** 나이가 들면서 여성만 선택적으로 진보화되며 gap이 확대되는 구조다.

### 유의한 통제변수

- **진학계획** (B = -0.048, p = .007): 상위대 지향 학생일수록 덜 반페미니즘
- **부모와 정치대화** (B = -0.062, p = .004): 정치 대화 빈번할수록 덜 반페미니즘
- **온라인 커뮤니티** (B = +0.067, p < .001): 커뮤니티 활용 많을수록 반페미니즘적
